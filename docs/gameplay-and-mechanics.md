# 游戏机制与数值设定手册

本文档汇总 **SkyGuard** 的基础运行参数、飞机单位属性、道具效果及观察者响应矩阵，以及三种难度模式的初始配置与动态递增规则（所有数值均以当前源码实现为准）。

---

## 1. 基础窗口与游戏循环参数

- **窗口分辨率**：`512 × 768`（`Main.WINDOW_WIDTH` × `Main.WINDOW_HEIGHT`）
- **帧率与主循环周期**：`timeInterval = 40 ms`（即每秒 `25` 个逻辑 Tick，每 `250` Tick = `10` 秒触发一次难度检查）
- **操控方式**：
  - 鼠标左键按住拖拽控制英雄机（`HeroController` 监听 `mouseDragged`，并限制在窗口边界内；暂停状态下锁定位置）
  - 键盘 `P` / `SPACE`：暂停或继续当前对局（屏幕中央显示半透明暂停提示）
  - 键盘 `M`：实时开启或静音游戏音效与背景音乐
- **碰撞判定**：
  - 敌机与英雄机相撞：敌机立即坠毁，英雄机生命值直接清零（游戏结束）
  - 子弹命中：扣除对应 `power` 伤害，子弹消失
  - 道具拾取：立即触发效果，播放 `get_supply.wav` 并消失

## 2. 飞机单位与弹道属性一览

| 单位名称 | 类名 | 初始血量 | 移动速度 (`speedX`, `speedY`) | 弹道策略 | 单轮发弹数 / 伤害 | 击毁得分 | 道具掉落机制 |
| :--- | :--- | :---: | :---: | :--- | :---: | :---: | :--- |
| **英雄机** | `HeroAircraft` | `250` | 鼠标拖拽控制 | 默认 `Straight`；火力切换 `Scatter` / `Circle` | 默认 `1` 发 / `50`<br>火力 `4` 发 / `50`<br>超火 `15` 发 / `50` | — | — |
| **普通敌机** | `MobEnemy` | `25` | `(0, 7)` 向下直行 | `NoShootStrategy` | 不发射 | `15` | 不掉落 |
| **精英敌机** | `EliteEnemy` | `45` | `(0, 7)` 向下直行 | `DoubleStraightShootStrategy` | `2` 发 / `10` | `15` | `60%` 概率掉落 1 个（加血 / 火力 / 超火） |
| **精锐敌机** | `ElitePlusEnemy` | `65` | `(±3, 5)` 斜向反弹移动 | `DoubleStraightShootStrategy` | `2` 发 / `13` | `35` | `75%` 概率掉落 1 个（加血 / 火力 / 超火 / 炸弹） |
| **王牌敌机** | `EliteProEnemy` | `85` | `(±3, 5)` 斜向反弹移动 | `ScatterShootStrategy` | `3` 发 / `20` | `45` | `95%` 概率掉落 1 个（含冰冻在内全部 5 种） |
| **Boss 敌机** | `BossEnemy` | `280` / `300` / `360+` | `(±3, 0)` 顶部左右巡航 | `CircleShootStrategy` | `25` 发 / `25` | `120` | 必掉落 `3` 个（全部 5 种随机抽取） |

> [!NOTE]
> `BossEnemy` 的血量随游戏难度而异：在 `NormalGame` 中固定为 `300`，在 `HardGame` 中初始为 `360` 且每次召唤后递增 `100`；`EnemyFactory` 中的 `BossEnemyFactory` 默认基准值为 `280`。

## 3. 补给道具与观察者效果矩阵

所有道具向下匀速下落（`SUPPLY_SPEED_Y = 6`），出界后自动销毁。

### 3.1 常规增益道具

| 道具名称 | 类名 | 生效逻辑 |
| :--- | :--- | :--- |
| **加血道具** | `BloodSupply` | 为英雄机恢复 `30` 点生命值，上限不超过 `maxHp`（`250`） |
| **火力道具** | `FireSupply` | 启动 `FirePowerRunnable`，将英雄机切换为 `4` 发扇形散射（`ScatterShootStrategy`），持续 `8` 秒后按版本号安全恢复直射 |
| **超级火力道具** | `FirePlusSupply` | 启动 `FirePowerRunnable`，将英雄机切换为 `15` 发全向环射（`CircleShootStrategy`），持续 `8` 秒后按版本号安全恢复直射 |

### 3.2 全屏控场道具（观察者模式多态响应）

拾取 `BombSupply` 或 `FreezeSupply` 后，由 `BombPropSubject` / `FreezePropSubject` 向当前屏幕内所有有效敌机与敌方子弹广播通知：

| 观察者目标 | 炸弹道具响应 (`onBomb()`) | 冰冻道具响应 (`onFreeze()`) |
| :--- | :--- | :--- |
| **普通敌机 (`MobEnemy`)** | 立即坠毁，玩家获得 `+15` 分（不掉道具） | 永久静止（`speedX = 0, speedY = 0`） |
| **精英敌机 (`EliteEnemy`)** | 立即坠毁，玩家获得 `+15` 分（不掉道具） | 静止 `4` 秒后恢复原速度 |
| **精锐敌机 (`ElitePlusEnemy`)** | 立即坠毁，玩家获得 `+35` 分（不掉道具） | 静止 `3` 秒后恢复原速度 |
| **王牌敌机 (`EliteProEnemy`)** | 扣除 `40` 点血量；若血量归零坠毁则获得 `+45` 分 | 移动速度降为 `50%`，持续 `5` 秒后恢复 |
| **Boss 敌机 (`BossEnemy`)** | 免疫，不受影响（`+0` 分） | 免疫，不受影响 |
| **敌机子弹 (`EnemyBullet`)** | 立即清除消失 | 原地静止 `5` 秒后恢复飞行 |

## 4. 三种难度模式配置与时间曲线

| 配置维度 | 简单模式 (`EasyGame`) | 普通模式 (`NormalGame`) | 困难模式 (`HardGame`) |
| :--- | :--- | :--- | :--- |
| **背景贴图 / 榜文件** | `bg.jpg` / `score_easy.txt` | `bg2.jpg` / `score_normal.txt` | `bg5.jpg` / `score_hard.txt` |
| **同屏最大敌机数** | `5` | `6` | `7` |
| **敌机初始生成周期** | `32` ticks (`1.28 s`) | `28` ticks (`1.12 s`) | `24` ticks (`0.96 s`) |
| **英雄机初始射击周期** | `20` ticks (`0.80 s`) | `20` ticks (`0.80 s`) | `22` ticks (`0.88 s`) |
| **敌机初始射击周期** | `26` ticks (`1.04 s`) | `22` ticks (`0.88 s`) | `18` ticks (`0.72 s`) |
| **普通/精英/精锐/王牌生成概率** | `50%` / `28%` / `15%` / `7%` | `38%` / `28%` / `22%` / `12%` | `28%` / `28%` / `24%` / `20%` |
| **Boss 触发机制** | **不生成 Boss** | 每累计 `900` 分触发 1 次；血量固定 `300` | 每累计 `700` 分触发 1 次；初始 `360`，每次生成后下次 `+100` |
| **每 10 秒难度递增规则** | 无递增，全程保持初始参数 | 1. 生成周期 `-2`（下限 `12`）<br>2. 敌机速度 `+1`（含当前在场普通敌机）<br>3. 敌机血量分别 `+2 / +3 / +4 / +5` | 1. 生成周期 `-2`（下限 `8`）<br>2. 英雄机射击周期 `-1`（下限 `10`）<br>3. 敌机射击周期 `-1`（下限 `8`）<br>4. 敌机速度 `+1`（含在场）<br>5. 敌机血量分别 `+3 / +5 / +6 / +8` |

## 5. 音频控制与 HUD 交互规则

游戏运行时通过 `MusicManager` 与守护线程 `MusicThread` 控制音效：

1. **音效总开关**：玩家可在开始菜单勾选/取消“开启游戏音效”，也可在对局中随时按 `M` 键切换静音；静音后立即停止当前循环音轨并拦截后续单次音效。
2. **游戏背景音乐 (`bgm.wav`)**：音效开启时，进入对局即循环播放，直到英雄机阵亡结束。
3. **Boss 背景音乐 (`bgm_boss.wav`)**：Boss 登场时循环播放，Boss 坠毁（或碰撞消失）后或游戏结束时立即停止。
4. **战斗事件单次音效**：
   - 子弹命中敌机：`bullet_hit.wav`
   - 拾取道具：`get_supply.wav`
   - 炸弹触发：`bomb_explosion.wav`
   - 游戏结束：`game_over.wav`
5. **可视化 HUD 与结算闭环**：
   - 左上角实时渲染模式、分数、英雄机生命值及绿/黄/红三段渐变血条；
   - Boss 在场时于顶部中央渲染 `BOSS HP` 进度条；
   - 对局结束弹出排行榜后，除保存、删除与刷新记录外，可直接点击“返回主菜单”继续下一局。
